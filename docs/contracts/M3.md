- 展示名：系统分配 / 建档 / 商机 / 跟进

## HTTP（本步相对 M2 增补）

M2 已有 ingest / leads / confirm / reject / abort-run / usage / health。本步控制台还用：

| 方法 | 路径 | 说明 |
|---|---|---|
| POST | `/api/leads/:id/stage` | `{ stage }`。中间阶段直接改；赢单/丢单生成待确认。viewer 403 |
| POST | `/api/leads/:id/abort` | 按线索清排队 |
| GET | `/api/handoffs/pending` | 跨线索待确认队列 |
| GET | `/api/similar?company=` | sqlite-vec 相似（杭齿→嘉兴精工装备；邻里鲜→夜灯便利） |
| GET | `/api/leads` | 列表含 `oppStage` |

语义不可改成四个 Agent 同时开工。不要把 Agent 端口暴露给浏览器。
