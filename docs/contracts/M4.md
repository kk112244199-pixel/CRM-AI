# 契约 M4（Docker + nginx）

后续步骤把本文与 [M0.md](./M0.md)、[M0.5.md](./M0.5.md)、[M1.md](./M1.md)、[M2.md](./M2.md)、[M3.md](./M3.md) 一起当作硬约束。要改先改 PRD 并问人。

## 已交付

- 仓库根 `docker-compose.yml`：`nginx` + `api` + `web`
- `deploy/nginx.conf`：`/` → web 静态；`/api/` → api:3001
- `deploy/Dockerfile.api`：Node 跑 harness HTTP；`HENGCE_DB=/data/hengce.db`
- `deploy/Dockerfile.web`：Vite 构建物进 nginx，**不含** `apps/web-demo`
- named volume `hengce-data` 持久化 SQLite
- 无 Redis、无 RabbitMQ、无独立 Grafana/Prometheus

命令：

```text
docker compose up --build
# 浏览器 http://127.0.0.1/  （宿主机 80）
```

无密钥（默认）：

```text
docker compose up --build
```

控制台能看到 8 家种子；橙果仍可用 scripted 走转化/外发。不要把无密钥记成黄金切片真模型已通过。

有密钥：

```text
# PowerShell
$env:DASHSCOPE_API_KEY="sk-..."
docker compose up --build
```

密钥只进 `api` 容器，不进 nginx/web 镜像。

## 拓扑

```text
浏览器 :80
  nginx
    /      -> web 容器（静态 SPA）
    /api/* -> api 容器 :3001
api
  volume hengce-data:/data
  读 runtime/agents 与 runtime/skills（打进 api 镜像）
```

不要把 3001 或 Agent 端口映射到宿主机。

## 数据

| 路径 | 说明 |
|---|---|
| `HENGCE_DB=/data/hengce.db` | 容器内库文件，落在 volume |
| 首次无库 | api 启动时 `bootstrapFileDb` 写入种子 |
| 语料 | 打进 api 镜像的 `data/corpus`，不靠 volume |

无充值表。刷新浏览器不丢 volume 里的库。
